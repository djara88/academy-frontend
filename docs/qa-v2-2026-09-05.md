## Revisión transversal Web Interface Guidelines

Confirmado en la PR:

- No se mantiene el `transition-all` global anterior.
- El sistema compartido usa `focus-visible`.
- Se preserva reduced motion.
- Se preservan safe areas móviles.
- Se retiraron múltiples capas `*-fix`, `*-polish`, `*-contrast-lock` y generaciones visuales completas en vez de cubrirlas con nuevos overrides.
- El sistema de color conserva semántica: marca/acción, éxito, pendiente y error/destructivo son categorías distintas.
